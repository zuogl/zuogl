## Hi, I'm lay zuo

I build practical web tools and maintain fan resources. Here are a few projects:

- [PokeSurvivor Hub](https://pokesurvivorhub.wiki) — an unofficial fan guide to PokéSurvivor with beginner guides, builds and move evolution references. It is not affiliated with Nintendo or the game developer.
- [WatermarkPilot](https://watermarkpilot.com) — add text or logo watermarks to supported photos and text watermarks to supported PDFs; files stay on your device.
- [GifLoom](https://gifloom.com) — compress GIFs locally in the browser with controls for scale, frame rate and color quality; target size is not guaranteed.
- [Square Footage Calculator](https://squarefootagecalculator.co) — calculate room area using feet and inches or metric measurements, with several shapes and measured sections.
- [Small Text Studio](https://bestsmalltext.online) — compare small caps, superscript and subscript Unicode styles; compatibility varies across platforms.
- [Sonify](https://sonify.uk) — a YouTube-to-MP3 converter and browser player. Conversion uses servers and temporary storage; only convert content you have rights and permission to use.
